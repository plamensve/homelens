# HomeLens – анализатор на обяви за имоти

Chrome разширение (Manifest V3) за анализ на обяви в `imot.bg`, `homes.bg` и `olx.bg`.

## Функции

### Безплатен план

- автоматично разпознаване на цена, площ, локация, тип, стаи и етаж;
- цена на квадратен метър;
- ипотечна вноска и първоначални разходи;
- локална история на посетените обяви за 30 дни;
- до 5 запазени имота;
- настройки за лихва, срок, самоучастие и ремонт.

### Premium

- неограничени запазени имоти;
- сравнение с локално натрупани сходни обяви;
- пълна история на цените;
- брутна и нетна доходност от наем;
- CSV експорт;
- лицензиране и абонамент чрез Lemon Squeezy.

> HomeLens не е професионална оценка. Пазарната оценка става по-полезна с натрупването на реални наблюдения. Версия 1.0 не изпраща обявите към централен сървър.

## Локален тест

1. Отвори `chrome://extensions`.
2. Включи **Developer mode**.
3. Избери **Load unpacked**.
4. Посочи папката `extension`.
5. Отвори конкретна обява в поддържан портал.

## Проверка и пакетиране

```bash
npm test
npm run validate
npm run package
```

Готовият архив се създава в `dist/` и съдържа `manifest.json` в корена, както изисква Chrome Web Store.

## Активиране на плащанията

Виж [MONETIZATION.md](MONETIZATION.md). Преди публикуване на платената функционалност попълни checkout адресите и product ID стойностите в `extension/src/constants.js`, след което промени версията и пакетирай отново.
